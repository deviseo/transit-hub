# 分组贡献利润瞬时超时修复需求快照

## 目标

修复首页“分组贡献”利润视图会因单个上游 key/token 的瞬时请求超时而整体不可用的问题。

## 需求与成功标准

- 上游 key/token 用量查询遇到一次瞬时失败时，在受控次数和时限内重试；重试成功后正常返回分组利润。
- 重试全部失败时，仍保持利润不可用，不能把未知成本当作零。
- 保持现有分组利润公式、分组名严格对齐、营收兼容字段、数据库结构和页面交互不变。

## 固定约束

- 站点和 key/token 查询并发上限不得提高。
- 重试必须有固定上限与请求时限，避免页面请求无限等待或放大上游压力。
- 不新增持久化数据、不修改上游配置、不提交代码。
