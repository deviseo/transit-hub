# 主站调度按钮状态色修复

## 目标

让健康探测页面的主站调度按钮直接体现当前状态：可调度时整个按钮为绿色，停用时保持原有白色或灰色外观。

## 实际改动

- 将可调度状态从仅绿色图标改为绿色按钮背景和白色图标，停用状态样式不变。
- 增加定向回归测试，固定两种状态的样式约定。
- 应用版本递增为 `V2.0.3`，同步后端、前端、设置页和生产镜像标记。

## 验证结果

- 主站调度按钮定向回归测试通过（2 个断言）；前端类型检查与生产构建通过，构建仅有依赖包既有的 Rollup 注释提示。
- 固定服务已按原连接目标重启：前端 `5444`、后端 `5555` 健康，PostgreSQL/Redis 连接与重启前一致，关键计数和 workspace 指纹未变化。
- 浏览器复查确认：可调度按钮背景为 `rgb(5, 150, 105)`、文字和图标为白色；停用按钮保持透明背景和原有灰色文字/图标，两个按钮尺寸均为 `28×28`。
