# V0.1.15K：分组健康前端两处修复

## 问题一：隐藏未监控账号勾选后无效

`shouldHideUnmonitored` 附带了 `!isNotProbed(account) && account.probeAvailable` 两个额外条件，导致绝大多数未监控账号（probeAvailable 为 false，或尚无健康数据）永远不满足隐藏条件，勾选后没有视觉变化。

修复：去掉多余条件，只判断 `!monitoringEnabled(account)`。

## 问题二：探活暂停时延迟列仍显示上次成功的 ms 值且无红色

账号处于 `suspended` 状态时，`lastLatencyMs` 保留的是最后一次成功探活的值，渲染层直接展示，看起来如同探活正常。实际应如实体现当前异常状态。

修复：主表格延迟列与展开行的模型延迟，在 `suspended` 状态下强制显示红色 `-`，不再展示 `lastLatencyMs` 中残留的上次成功值。

`frontend/src/modules/admin/components/dashboard/AdminGroupHealthDetail.vue`
